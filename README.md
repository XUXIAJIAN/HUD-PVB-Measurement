# PVB 楔角分析

离线运行的 PVB 厚度与楔角分析工具，支持 CSV、Excel、多样本比较和平均曲线。

## 下载和使用

1. 点击本页面绿色 **Code** 按钮，选择 **Download ZIP**。
2. 完整解压下载的文件。
3. 双击 `index.html`，用 Edge 或 Chrome 打开，保留 `vendor` 文件夹。

无需安装 Python、Node 或额外依赖，测量数据在本地处理。

## 生成平均曲线

导入多个文件后，点击“选择样本，生成平均曲线”，勾选至少两个样本即可。
按位置线性插值对齐厚度，各样本等权平均；只使用共同范围，遇到缺失数据保留断点。
平均曲线名称自动取自所选 CSV 文件名，去掉扩展名，并将 `data` 后的日期时间缩短为八位日期。例如 `ESM_data202611031505220_ESM1100.csv` 标注为 `AVE_ESM_data20261103_ESM1100`。相同标注合并，不同标注以顿号连接；也可手动修改名称。标注显示在图例、读数表和导出结果中。
结果保留为独立曲线，原始样本保留，可切换厚度／楔角、读取眼盒位置数值并导出。

详细算法和使用方式见 `使用说明.txt`。示例按钮使用随包附带的测量示例。

第三方库：Plotly.js 2.35.2、SheetJS CE 0.20.3；许可证保存在 `vendor` 中。

平均曲线名称统一带有 `AVE_` 前缀。显示中的平均线名称会按曲线颜色标注在绘图区内，名称用同色线段连接到当前显示范围内的平均曲线数据点（无可见有效点时不连线），长名称自动换行，隐藏曲线时标注同步隐藏；导出图片也会包含标注。

图表高度随样本图例数量自动增加，为曲线保留约 420 像素的绘图区。

可以用鼠标直接拖动平均线名称框，连接线会跟随名称移动，曲线数据保持不变。拖动位置在当前页面内保留，隐藏再显示、修改计算设置后仍沿用；厚度和楔角视图分别记忆位置，刷新页面后重置。导出图片保留当前标注位置。

点击左侧样本名称旁的颜色方块可手动修改颜色，曲线、平均线名称和连接线同步更新。新曲线优先使用尚未占用的色板颜色；当前页面内保留修改后的颜色。

## 局部楔角调整与原格式导出

点击“载入本次 SEKG65 检测样本”，或导入自己的 CSV。在“局部楔角调整”中选择样本和起止位置，输入楔角增量或区间平均楔角目标（mrad），预览后应用。支持多次调整、撤销一步和恢复原始数据；虚线显示原始曲线。

以区间内恒定的斜率修正积分得到厚度修正：区间左侧固定，区间内厚度连续线性变化，右侧整体平移。目标模式求解当前窗口及平滑条件下，区间有效采样点楔角算术平均达到目标所需的修正量；不表示每个位置都达到同一楔角。有限窗口在边界附近产生过渡。

“导出同格式厚度 CSV”只导出选定 CSV 样本的厚度数据，保留原始表头字节、位置列、行序、换行、其他列和厚度小数位。未修改时导出与输入逐字节一致。Angle、Intercept、R2 等仪器表头保持原始记录，不会更新为调整后结果；导出舍入后再计算的楔角可能与预览略有差异。Excel 和合成平均曲线仍使用原有分析导出，不提供原格式回写。所有编辑保存在内存，刷新前请导出。

无需安装依赖；完整解压后打开 index.html。若浏览器限制本地文件，可在此目录运行 `python3 -m http.server 8000 --bind 127.0.0.1`，再通过浏览器访问该本地服务。

核心算法与格式保持测试：`node tests/wedge.cjs`。

### 多区间独立撤销

每次应用调整都会新增一条区间记录。可以先调整 A 段，再调整 B 段，然后在记录中单独撤销或恢复任意一段；“撤销一步”撤销最后一条仍生效的记录。撤销按该段实际应用的厚度修正量移除，保留其他记录的修正量；重叠区间也支持。目标平均值是在该条应用时求得的，其他段变化后不会自动重新求目标。若撤销或恢复会导致非正厚度，操作会被拒绝并保留当前状态。

点击“确认并导出厚度 CSV”后，先核对最终生效区间清单，可返回继续调整，确认后才下载；已撤销记录不计入导出。所有记录仅保存在当前页面内存中。

浏览器功能检查（需已安装 Playwright 与 Chromium，并启动本地服务）：`node tests/history-browser.cjs`。可通过 `PVB_TEST_URL` 指定本地服务地址，默认端口 8000。
