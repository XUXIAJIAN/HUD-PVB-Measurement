# PVB 楔角分析

离线运行的 PVB 厚度与楔角分析工具，支持 CSV、Excel、多样本比较和平均曲线。

## 下载和使用

1. 点击本页面绿色 **Code** 按钮，选择 **Download ZIP**。
2. 完整解压下载的文件。
3. 双击 `index.html`，用 Edge 或 Chrome 打开，保留 `vendor` 文件夹。

无需安装 Python、Node 或额外依赖，测量数据在本地处理。

## 生成平均曲线

导入多个文件后，点击“选择样本，生成平均曲线”，勾选至少两个样本即可。
按位置线性插值对齐厚度，各样本等权平均；只使用共同范围，遇到缺失数据保留断点。
平均曲线名称自动取自所选 CSV 文件名，去掉扩展名，并将 `data` 后的日期时间缩短为八位日期。例如 `ESM_data202611031505220_ESM1100.csv` 标注为 `AVE_ESM_data20261103_ESM1100`。相同标注合并，不同标注以顿号连接；也可手动修改名称。标注显示在图例、读数表和导出结果中。
结果保留为独立曲线，原始样本保留，可切换厚度／楔角、读取眼盒位置数值并导出。

详细算法和使用方式见 `使用说明.txt`。示例按钮使用随包附带的测量示例。

第三方库：Plotly.js 2.35.2、SheetJS CE 0.20.3；许可证保存在 `vendor` 中。

平均曲线名称统一带有 `AVE_` 前缀。显示中的平均线名称会按曲线颜色标注在图表上方的独立留白区，长名称自动换行，隐藏曲线时标注同步隐藏；导出图片也会包含标注。
